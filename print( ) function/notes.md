## 1. What is the print() function?

**Definition:** `print()` is a built-in Python function that displays output on the screen. Whatever you put inside the parentheses is shown when the program runs.

**Syntax:**
```python
print(value)
```

## 2. Why do we use print()?

- To display results of a program on the screen
- To show messages and text to the user
- To display the result of calculations
- To check values while writing code

## 3. How to print text

Text (also called a **string**) must be written inside quotation marks (single or double).

```python
print("Welcome to Python")
```

## 4. Printing values

- **Numbers** do not need quotation marks. Python understands them as numbers.
- **Multiple values** can be printed in one statement by separating them with a comma.
- **Calculations** can be written directly inside `print()`.

## 5. Understanding the output

The output is what appears on the screen after you run the code. Each `print()` statement shows its result on a new line.

---

## Examples

### Example 1: Hello World
```python
print("Hello World")
```
**Output:**
```
Hello World
```
The `print()` function displays `Hello World` on the screen. The text is placed inside double quotes.

### Example 2: Text Print
```python
print("Welcome to Python")
```
**Output:**
```
Welcome to Python
```
When printing text (a string), it must be placed inside quotation marks.

### Example 3: Numbers Print
```python
print(10)
print(25)
```
**Output:**
```
10
25
```
Numbers do not need quotation marks, because Python understands them as numbers.

### Example 4: Multiple Values
```python
print("My age is", 19)
```
**Output:**
```
My age is 19
```
You can print multiple values in a single `print()` statement by separating them with a comma.

### Example 5: Addition
```python
print(10 + 20)
```
**Output:**
```
30
```
Python performs the calculation inside `print()` and displays the result.

### Example 6: Multiplication
```python
print(5 * 6)
```
**Output:**
```
30
```
Multiplication works the same way. Calculations can be displayed directly using `print()`.

### Final Example
```python
print("My name is Dharshu")
print(10 + 5)
```
**Output:**
```
My name is Dharshu
15
```
The first `print()` displays the name. The second one calculates 10 + 5 and displays `15`.

---

## Key Points

- `print()` displays output on the screen.
- Text (strings) must be inside quotation marks.
- Numbers do not need quotation marks.
- Use a comma to print multiple values in one statement.
- Calculations can be done directly inside `print()`.
