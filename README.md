## What's here

Every video has its own folder with the code I wrote in the video, plus short notes. Open the folder, run the code, change things and see what happens.

## How to run the code

**Option 1: Online (easiest)**  
Copy the code, open any online Python compiler, paste it and run.

**Option 2: VS Code**
1. Download this repo (green **Code** button → **Download ZIP**) and open the folder in VS Code.
2. Open the `.py` file.
3. Open the terminal (**Terminal → New Terminal**) and run: `python main.py`

> Option 2 needs Python installed. If you don't have it, use Option 1.
