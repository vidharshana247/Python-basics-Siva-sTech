## How to run the code

**Option 1: Online (easiest)** Copy the code, open any online Python compiler, paste it and run.

**Option 2: VS Code**

1. Download this repo (green **Code** button → **Download ZIP**) and open the folder in VS Code.
2. Open the `.py` file.
3. Open the terminal (**Terminal → New Terminal**) and run: `python main.py`

> Option 2 needs [Python](https://www.python.org/downloads/) installed. If you don't have it, use Option 1.
